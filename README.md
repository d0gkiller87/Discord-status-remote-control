## Introduction
Ever wanted to log in to Discord invisibly, but your last status was set to online/idle/dnd?  
That's unfortunate, now you have to be online before you can switch to invisible again. Exactly why this tool was born!

Now you can visit the homepage (https://discord.com/) and this script will show a menu allowing you to ***secretly*** change your last online status! All the changes made with this menu are synced to Discord's server directly, and will be your first status when you enter the app. Isn't that handy🙂
